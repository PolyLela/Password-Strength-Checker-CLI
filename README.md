#Simple Password Strength Checker (CLI Project)
📌 Overview

This project is a simple password strength checker made in node.js CLI.
It was built as a learning exercise to understand how keyboard input is handled at a low level in Windows and to gain hands‑on experience with system programming concepts.

🎯 Motivation

The main goals of this project were to Deepen Javascript knowledge

🛠️ Technologies Used

node.js
readline library

✨ Features

Asks user to type password
Check the password strength by counting each number and symbol and if the overall number
tell them whether its Weak or Medium or Strong
Simple and readable implementation
